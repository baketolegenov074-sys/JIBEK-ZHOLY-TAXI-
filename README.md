# Bake Taxi

**Bake Taxi** — платформа для поездок и сервисов по Шымкенту и Казахстану.

Доступные направления:
- Городское такси: Эконом, Комфорт и Бизнес.
- Междугородние поездки.
- Доставка посылок.
- Грузовые перевозки.
- Эвакуатор.
- Выездной шиномонтаж.

В репозитории находятся приложения пассажира, водителя и владельца, а также общий код и серверный API.
